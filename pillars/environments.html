RL Environments

An RL environment is a place where an AI agent can try something, fail, and learn from the result. We build Indian ones: apps and websites with their own data and rules, businesses that run for weeks, reasoning problems and coding tasks. Every task ends in a state that code can check, so the same environment can train an agent and test it.

How we check

A task ends in a state, not an opinion

When the agent stops, a program reads the environment's records and decides. The same check is the reward for training and the score for a benchmark.

  1. 1A goal in plain language“Book a train ticket from Delhi to Jaipur for my mother, who needs a lower berth.”
  2. 2The agent works the appThrough its tools, or on screen: searching trains, picking a berth, paying by UPI.
  3. 3The database changesA booking row with a PNR (the booking number on every Indian Railways ticket), a passenger, a berth and a fare.
  4. 4Code checks the resultIs there a lower berth, for the right passenger, on the right train? Yes or no.
